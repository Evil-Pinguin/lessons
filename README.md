# Уроки+ — сайт услуг по созданию интерактивных упражнений

Одностраничный сайт для педагога (Анжелина Михайловна, zloipingvin2000@gmail.com): заказ интерактивных ИКТ-упражнений для дошкольников и школьников — викторины, «найди пару», «собери слово», сортировка, «верно/неверно», мемори.

- Светлая тема с белым фоном по умолчанию, градиент в стиле Gemini, эффект «жидкого стекла»
- Темы: светлая / тёмная / красочная / своя (палитра сохраняется в браузере)
- Живые демо-упражнения со звуком (Web Audio); голосовая озвучка заданий (Web Speech) включается кнопкой «Голос» в шапке
- Все иллюстрации — сгенерированные картинки в `img/` (hero, pairs, word, memory, ui)
- Блок «Есть своя идея?» — предложение подставляется в форму заявки
- Редактирование упражнений «под себя» с сохранением в `localStorage`
- Форма заявки → Supabase (с запасным вариантом через `mailto:`)
- Цены от 500 ₽ по сложности, срок 2–3 дня

## Запуск

Статический сайт без сборки. Откройте `index.html` или запустите любой сервер:

```bash
python3 -m http.server 8080
```

## Публикация и Supabase

Подробная инструкция: **[DEPLOY.md](DEPLOY.md)** — Vercel, переменные окружения, SQL для базы.

## Подключение Supabase без Vercel (GitHub Pages и т. п.)

1. Создайте проект на [supabase.com](https://supabase.com).
2. В **SQL Editor** выполните `supabase/schema.sql` (таблица `requests` + RLS: анонимные могут только добавлять).
3. Скопируйте **Project URL** и **anon public key** из *Settings → API* в `js/supabase-config.js`.
4. Заявки будут видны в *Table Editor → requests*.

Пока ключи не заполнены, кнопка «Отправить» открывает почтовый клиент с готовым письмом.

## Структура

```
index.html             — разметка
css/styles.css         — стили, темы (data-theme), стекло, анимации
js/audio.js            — звуки и озвучка
js/theme.js            — переключение тем, своя палитра
js/exercises.js        — 6 демо-упражнений + редактор/хранилище
js/app.js              — навигация, мини-демо, форма, Supabase
js/supabase-config.js  — ключи Supabase
supabase/schema.sql    — SQL для таблицы заявок
```
